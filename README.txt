DESA WISATA KADUELA — WORDPRESS THEME
======================================

INSTALASI
1. Masuk ke WordPress Admin > Tampilan > Tema > Tambah Tema > Unggah Tema.
2. Pilih file desa-wisata-kaduela-wordpress-theme.zip, lalu klik Instal dan Aktifkan.
3. Selesai. Theme otomatis membuat seluruh halaman, menetapkan Beranda sebagai halaman depan, dan memasang navigasi internal tanpa pengaturan menu manual.

BERITA DINAMIS
1. Masuk ke Pos > Tambah Baru.
2. Isi judul, tanggal publikasi, isi berita, dan Gambar Unggulan (Featured Image).
3. Klik Terbitkan. Berita otomatis tampil di Beranda (maksimal 3 terbaru), halaman Berita, dan halaman detail berita.
4. Jika belum ada Pos, halaman menampilkan pesan "Belum ada berita yang dipublikasikan."

HALAMAN STATIS
Beranda, Profil, Destinasi, Telaga Biru Cicerem, Wisata Side Land, Paket Wisata, Akomodasi, Suvenir, Budaya, dan BUMDes sudah tertanam di dalam theme beserta seluruh gambarnya. Tidak perlu menyalin isi HTML atau mengunggah gambar satu per satu melalui Media Library.

CATATAN UPDATE
- Mengganti atau memperbarui file theme tidak menghapus Pos berita karena Pos tersimpan di database WordPress.
- Aktivasi ulang theme tidak menggandakan halaman dan tidak menimpa halaman yang sudah ada.
- Sebelum mengganti theme di website aktif, tetap buat cadangan database dan folder wp-content sebagai praktik pemeliharaan standar.
